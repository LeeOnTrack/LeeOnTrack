# LeeOnTrack Website

This is a free static website ready for GitHub Pages.

## Files
- index.html
- styles.css
- script.js

## Publish on GitHub Pages
1. Create a free GitHub account if needed.
2. Create a new public repository called `leeontrack`.
3. Upload all three files from this folder.
4. Open repository Settings > Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will show the public website address after deployment.

## Customising
You can replace the four gallery placeholder panels with your own iRacing screenshots later.
